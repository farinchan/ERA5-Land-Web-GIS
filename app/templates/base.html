Tentang ERA5-Land Web GIS

Aplikasi Web GIS ini dibangun untuk memvisualisasikan dan menganalisis dataset reanalisis iklim ERA5-Land dari file NetCDF secara interaktif, efisien, dan tanpa mengirim raw file NetCDF ke browser.

Eksplorasi Variabel

Pilih variabel temperatur, presipitasi, kelembaban tanah, tekanan permukaan, evaporasi, atau angin.

Query Titik & Time Series

Klik di sembarang titik daratan pada peta untuk melihat nilai koordinat dan time series interaktif (ECharts).

Analisis Poligon Spasial

Gunakan tombol poligon di peta untuk menggambar batas penelitian dan menghitung statistik spasial otomatis.

Vektor Angin & Batas Wilayah

Aktifkan layer vektor arah/kecepatan angin dan batas wilayah administratif Sumatera.
